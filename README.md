# Ultima Warriors desktop wallpapers

Personal desktop backgrounds for a 5120 × 1440 screen. This branch is separate from the
website. It has its own history, is never merged into `main`, and is never published to the site.

## `neon-street-still/` (current)

`UltimaWarriors-Neon-Edge-5120x1440.jpg`: a rainy street on the edge of a cyberpunk city at night,
with the **ULTIMA WARRIORS** neon sign on the wall in the middle. Dim, sparse city lighting, no
clock. It's a plain picture, so it uses no extra graphics memory.

To set it: right-click → **Set as desktop background** (or Settings → Personalization →
Background → Picture, fit **Fill**).

## `neon-street-animated/` (v1.2)

The animated version: the neon sign lights up and flickers, plus a live neon clock, rain, steam,
haze and air traffic over the brighter street. Runs in Wallpaper Engine or Lively Wallpaper
(open `index.html`); see `README.txt` inside for setup and on/off switches. Set aside for now
because it was too heavy on graphics memory on this PC.

Street images were generated with Runway; the sign, clock and effects are drawn in code.
