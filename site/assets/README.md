# Artwork

The site expects these images here:

| File | Used for |
| --- | --- |
| `space-bg.webp` / `space-bg-1920.webp` | Continuous space background (desktop / phone) |
| `intro.webp` / `intro-1920.webp` | First-visit welcome banner (desktop / phone) |
| `mech.webp` | Mech beside the welcome text (transparent background) |

All artwork was AI-generated with Runway at 4K and compressed to WebP for fast loading.
`mech.webp` has a transparent background so it floats over the space backdrop.
