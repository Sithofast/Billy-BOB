# Artwork

| File | Used for |
| --- | --- |
| `space-bg.webp` / `space-bg-1920.webp` | Continuous space background (desktop / phone) |
| `intro-bg.webp` / `intro-bg-1920.webp` | Welcome banner background: planet and space, no mech (desktop / phone) |
| `intro-mech.webp` | Welcome banner mech (transparent background), floats over the planet |
| `clouds.webp` | Seamless cloud texture that drifts across the planet in the welcome banner |
| `mech.webp` | Mech beside the welcome text (transparent background), flies in on load |

The artwork was AI-generated with Runway at 4K and compressed to WebP for fast loading.
The cloud texture was generated by code (seamless noise), so it repeats with no visible join.
The welcome banner's layers line up with each other: the planet edge and mech position are
measured from the original 5504 × 3072 artwork (see the `intro-sky` SVG and `.intro-mech` in
`styles.css`), so replace `intro-bg` and `intro-mech` together if you change them.
